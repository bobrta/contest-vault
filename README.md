# Contest Vault 🏆

競賽戰略庫、注意事項防雷清單與報告簡報資源庫。

## 快速開始

1. 參賽前：核對[賽前規則與評分標準](checklists/rules-and-criteria.md)。
2. 準備報告：使用[路演簡報大綱](templates/pitch-deck-outline.md)。
3. 上台前：完成[簡報與答辯檢查](checklists/presentation-prep.md)。
4. 每場競賽：依照[競賽歸檔說明](competitions/README.md)建立紀錄，賽後整理評審建議與改善事項。

## 目錄結構

```text
contest-vault/

│   └── presentation-prep.md

```

## 使用準則

- 官方簡章優先：範例評分比重不代表任何競賽的實際規定。
- 未確認的資格、日期及規格標示「待確認」，並留下官方來源。
- 本專案為公開儲存庫；上傳前移除個資、未公開研究及不適合公開的團隊資料。
